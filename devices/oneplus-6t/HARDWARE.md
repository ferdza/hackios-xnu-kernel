# OnePlus 6T (fajita) — hardware map

Read off the phone's own flattened device tree (`/sys/firmware/fdt`, LineageOS) and its
`/vendor/firmware` listings. These are the real numbers the HakiOS drivers must target; the
SDM845 reference guesses in `soc.args.sdm845-reference` are superseded by this.

## Identity (from the kernel bootargs in the device tree)
- `platform_name=SDM845`, `project_codename=fajita`, `project_name=18801`, `hw_version=41`
  → ABL board id **`<8 0 18801 41>`** (confirms the UniXNU figure)
- `bootdevice=1d84000.ufshc`, `usbcontroller=a600000.dwc3`
- `firmware_class.path=/vendor/firmware_mnt/image`

## Display
- Active panel: **`dsi_samsung_s6e3fc2x01_cmd_display`** — Samsung s6e3fc2x01, command mode, 1080×2340.
  (The tree also carries `sofef00_m` cmd/video nodes — those are the OnePlus 6 panel, inactive here.)
- MDSS MDP: **`0xae00000`**
- DSI controller 0: **`0xae94000`**; DSI controller 1: `0xae96000`
- Continuous-splash framebuffer: **`0x9d400000`** (`cont_splash_region`)

## Storage
- UFS host controller (UFSHC): **`0x1d84000`** — this is the first wall; XNU needs a UFS driver here
  before the APFS root can mount.

## Touch
- **Synaptics S3320**, RMI4, node `/soc/i2c@a90000/synaptics-rmi-ts@20`, compatible `HWK,synaptics,s3320`.
- Bus: **`i2c@a90000`**, compatible `qcom,i2c-geni` → GENI **I²C** serial engine at **0xa90000**
  (north QUP cluster, wrapper `qupv3_1_geni_se@ac0000`). I²C slave address **0x20**.
- IRQ: TLMM **GPIO 125** (`0x7d`, flags `0x2008`). Reset: TLMM **GPIO 99** (`0x63`).
- **Note the bus type:** the POCO's `hakios.goodix.c` is GENI **SPI**; fajita touch is GENI **I²C**.
  HakiOS has no GENI-I²C transport yet, so the touch port is a new driver (`hakios.synaptics.c`):
  GENI-I²C bring-up (GCC clock vote for the a90000 SE + TLMM i2c pinmux + RPMh rail votes) plus the
  RMI4 protocol (PDT scan, F01 device control, F11/F12 2D touch), feeding `hakios_touch_post()`.

## Fingerprint (later)
- Goodix optical in-display (`goodix,fingerprint` / `goodix_fp`); firmware `gfp9508.*`, `gfp5288.*`,
  and `fpc1228.*` present in `/vendor/firmware/`.

| `soc_gsi_base` | `0x1e04000` | GSI |
| `soc_rsc` | `0x179e0000` | apps RPMh RSC, **drv-2** (node is `rsc@179c0000`; drv-2 is +0x20000) |
| `soc_apps_smmu` | `0x15000000` | apps SMMU |
| `soc_smem` | `0x86000000` | `smem_region@86000000` |
| `soc_imem` | `0x14600000` | 2 MB block holding msm-imem |
| `soc_ipa_stream` | `0x720` | IPA SMMU AP stream |
| `soc_ipa_stream_uc` | `0x722` | IPA SMMU uC stream |
| `soc_pas_ipa` | `0xf` | IPA PAS id |
| `soc_ipa_fw` | `ipa_fws` | IPA firmware name |
| `soc_mpss_mem` | `0x8e000000` | `modem_region` (by hand from reserved-memory) |

### Not set yet (cellular-era, needs code not just an address)
- **`soc_ipcc`: does not exist on SDM845.** No `qcom,ipcc` node in the tree — the POCO's modem
  signalling path has no direct equivalent here; this is the structural part of the cellular port.
- `soc_aoss`: AOSS QMP mailbox. SDM845 is `0xc300000`; `soc-args.py` didn't match this tree's node
  name, so confirm before using.
- `soc_cmd_db`, `soc_pas_mpss`: not emitted by the generator on this tree; `qcom,mss@4080000` exists
  (MSS/modem), extract its `pas-id` and the `cmd_db` reserved region when cellular work begins.
- IPA version on SDM845 is **v3.5.1** (POCO is v4.11) — the IPA SRAM layout / filter-table / Qtime
  values hardcoded in `hakios.ipa.c` are for 4.11 and must be redone for 3.5.1.

## Other reserved-memory regions (for later)
`mba_region@0x96600000`, `adsp_region@0x8c500000`, `cdsp_region@0x95d00000`,
`slpi_region@0x96800000`, `video_region@0x95800000`, `gpu_region@0x8c415000`,
`wlan_fw_region@0x8df00000`, `hyp_region@85700000`, `xbl_region@85e00000`.

## Firmware blobs present on the device (LineageOS, OxygenOS-derived vendor)
- **GPU (Adreno 630):** `/vendor/firmware/` — `a630_gmu.bin`, `a630_sqe.fw`,
  `a630_zap.mdt` + `a630_zap.b00/b01/b02` (also `a630_zap.elf`).
- **IPA:** `/vendor/firmware/` — `ipa_fws.mdt` + `ipa_fws.b00..b04` (NOT in firmware_mnt).
- **Wi-Fi (WCN3990):** `/vendor/firmware_mnt/image/` — `wlanmdsp.mbn`, `bdwlan.*` board data,
  `data.msc`; plus a `/vendor/firmware/wlan/` subdir.
- **ADSP:** `/vendor/firmware_mnt/image/` — `adsp.mdt` + `adsp.b00..b13`, `adspr.jsn`, `adspua.jsn`.
- **Modem (MPSS):** `/vendor/firmware_mnt/image/` — `modem.mdt` + `modem.b00..b28`, `mba.mbn`,
  `qdsp6m.qdb`, `modemr.jsn`, `modemuw.jsn`.
- No separate haptics firmware (6T uses a plain vibration motor, not the POCO's Awinic part).
